# Binaire getallen – FTRPRF

Oefening uit **IT&ME**, module **Bits & Bytes** (FTRPRF): zet decimale getallen om naar binair en terug.

- 3 opgaven decimaal → binair, daarna 3 opgaven binair → decimaal (steeds moeilijker)
- Uitleg bij elke fout, een gifje bij elk juist antwoord
- Bit-rekenmachine als hulp
- Highscores (top 10) worden opgeslagen in de browser van de computer

## Online zetten met GitHub Pages

1. Maak een nieuwe repository op GitHub (bv. `binaire-getallen`).
2. Upload alle bestanden uit deze map (`index.html`, `scores.html`, `script.js`, `scores.js`, `styles.css`, `favicon.ico`, `logo.png`) via **Add file → Upload files**.
3. Ga naar **Settings → Pages**, kies bij *Source* **Deploy from a branch**, branch `main`, map `/ (root)` en klik **Save**.
4. Na een minuutje staat de site op `https://<jouw-gebruikersnaam>.github.io/binaire-getallen/`.
